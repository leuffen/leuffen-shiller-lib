# Shiller Demo

[repo/](repo/) ist die Wurzel eines vollständigen Beispiel-Website-Repositories.
Darin liegen `.shiller.yml`, `docs/`, `.shiller.d/` und `.shiller-context.d/`.
Alle relativen Konfigurationspfade beginnen in `repo/` und bleiben innerhalb
dieses Projekts. Die [Anleitung](repo/README.md) beschreibt die Ausführung.
