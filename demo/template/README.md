# Demo Template

Dieses Verzeichnis repraesentiert ein eigenstaendiges Template-Projekt. `_tpl/_root/docs/` enthaelt die Basiskonfiguration, strukturierte Daten und `_rules.d`; `_tpl/pages/` enthaelt die tag-basierten Markdown-Vorlagen.

Wird aus `demo/project` mit dem Tag `demo` installiert, zeigt die kopierte `.shiller.yml` zurueck auf dieses `_tpl`.
