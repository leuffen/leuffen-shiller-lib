# Projektspezifische Context-Build-Regeln

Diese Datei ergänzt ausschließlich die allgemeinen Regeln des mitgelieferten
Context-Build-Skills.

Die Demo soll als fiktives Beispiel erkennbar bleiben. Übernimm aus Rohdaten
nur Angaben zur Demo Praxis Nord und halte die Darstellung sachlich.

Kontaktdaten sollen im Abschnitt `Kontakt` stehen. Der fachliche Schwerpunkt
soll im Abschnitt `Projekt` erhalten beziehungsweise ergänzt werden.
