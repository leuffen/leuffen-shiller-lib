# AI Usage Info – Shiller

Shiller richtet eine Website aus den Vorlagen eines Theme-Pakets ein und passt
installierte Markdown- und YAML-Dateien an einen Projektkontext an.
Die [README.md](README.md) zeigt die CLI-Befehle in Ausführungsreihenfolge.
Für die Vorbereitung eines ThemeJS2-Pakets gilt der
[Shiller Theme Setup Skill](skills/shiller-theme-setup/SKILL.md).

## Verzeichnisstruktur

Das Theme-Paket liegt im Website-Projekt unter
`node_modules/@leuffen/themejs2/` und stellt `_tpl/` und
`skills/` bereit. `_tpl/_root/` wird bei `init` kopiert;
andere Vorlagen werden über Tags ausgewählt. Skills bleiben im Paket.

```text
website/
|-- .shiller.yml
|-- .shiller-context.d/
|   |-- project.md
|   `-- raw/
|-- docs/
|   |-- index.md
|   `-- _data/general.yml
`-- node_modules/
    `-- @leuffen/themejs2/
        |-- _tpl/
        |   |-- _root/
        |   |   |-- .shiller.yml
        |   |   |-- .shiller-context.d/project.md
        |   |   `-- docs/_data/general.yml
        |   |-- pages/index.base.md
        |   `-- instructions/index.md
        `-- skills/edit-website/SKILL.md
```

`_tpl/_root/docs/` wird zu `website/docs/`, andere
`_tpl/_root/`-Dateien in die Projektwurzel kopiert. `docs/`
ist der Standard-Document-Root. Die Startdatei
`.shiller-context.d/project.md` enthält die Website-Fakten.

## Beispiel für ein Theme-Template

`_tpl/pages/index.base.md`:

```markdown
---
shiller:
  tags: [base]
  target: index.md
  instructions:
    - tpl:/instructions/index.md
layout: website
title: Startseite
---
# Willkommen
```

Die Datei wird bei `--tags base` als `docs/index.md`
installiert. `shiller.tags` steuert die Auswahl,
`shiller.target` den Dateipfad relativ zum Document Root und
`shiller.instructions` die ergänzenden Bearbeitungshinweise.
Die referenzierte Datei `_tpl/instructions/index.md` muss
existieren. Für andere Textdateien dient das Suffix `.template`;
dabei werden der YAML-Header und das Suffix nicht ins Ziel übernommen.

Die kopierte `.shiller.yml` im Projekt-Root enthält:

```yaml
template_dir: node_modules/@leuffen/themejs2/_tpl
skills_dir: node_modules/@leuffen/themejs2/skills
```

## CLI: Projekt erstellen und Inhalte bearbeiten

Befehle in der Website-Projektwurzel ausführen; das PHP-Paket
`leuffen/shiller-lib` und das ThemeJS2-npm-Paket müssen vorhanden sein.

```sh
# Einmalig: Startstruktur und die Variante "base" installieren.
./vendor/bin/shiller init --template-dir ./node_modules/@leuffen/themejs2/_tpl --tags base

# Optional: weitere Variante gezielt installieren.
./vendor/bin/shiller install --tags "theme:osman"

# Nur wenn neue Rohdaten unter .shiller-context.d/raw/ liegen:
./vendor/bin/shiller context build

# Eine installierte Datei an Projektkontext und Theme-Skills anpassen.
./vendor/bin/shiller adapt --select index.md

# Alternativen: mehrere Dateien oder Original wiederherstellen.
./vendor/bin/shiller adapt --select "index.md,_data/general.yml"
./vendor/bin/shiller revert index.md
```
